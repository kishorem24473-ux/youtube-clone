## ✨ Features

- **Header Bar Navigation:**
  - YouTube branding with scalable SVG hamburger menu and logo.
  - Search bar complete with search and microphone action buttons.
  - User controls including "+ Create" button, notification bell, and user avatar.
- **Category Filter Ribbon:**
  - Scrollable filter buttons (All, Podcasts, Web Development, Gaming, etc.) styled to match the official desktop UI.
- **Multi-Section Sidebar:**
  - Persistent left-hand menu broken into structured groups: Primary navigation, Library/You, Explore, and Services.
- **Dual Content Feed:**
  - **Video Grid:** Structured video cards featuring thumbnails, duration badges, creator channel icons, verified creator badges, view counts, and upload timestamps.
  - **YouTube Shorts Shelf:** Horizontal row dedicated to short-form vertical video previews with custom view metrics.
- **Modular Stylesheet Architecture:**
  - Segregated CSS files (`header.css`, `side-bar.css`, `body.css`, `general.css`) for high maintainability and clean separation of concerns.

---

## 🛠️ Built With

- **HTML5:** Semantic layout structuring and embedded SVG vector icons.
- **CSS3:** Flexbox, CSS Grid layouts, custom positioning, and hover states.
- **Icons:** SVG graphics for crisp scaling across all screen densities.

## 📁 Project Structure
